# Field Service track

Fixes for Salesforce Field Service:

- Field Service mobile app configuration and behavior
- Scheduling: scheduling policies, work rules, service objectives, optimization
- Work orders and service appointments: lifecycle, statuses, automation
- Service resources, territories, and operating hours
- Field Service configuration and metadata generally

One folder per fix, following the repository convention: a problem statement, the complete change, and test/verification evidence. See the [repository README](../README.md).

Fixes here are authored and verified in scratch or developer orgs and submitted through TRIS before any use in a TDS org. No TDS data, org identifiers, or credentials belong in this track.
